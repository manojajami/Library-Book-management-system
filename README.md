# 📚 Library Book Management System

A simple **Library Book Management System** developed in **C** using **Arrays, Loops, Structures, Functions, and File Handling**. This project demonstrates the implementation of basic library operations such as adding books, issuing books, returning books, displaying available stock, and calculating fines for overdue returns.

---

## 📖 Overview

The system allows a librarian to manage book records efficiently while maintaining data permanently using text files.

The project is designed for educational purposes and helps beginners understand how file handling and data structures work together in C programming.

---

## ✨ Features

- Add new books
- Issue books to students
- Return books
- Display available stock
- Fine calculation for late returns
- Permanent data storage using files
- Menu-driven console interface

## 📂 Files Used

### books.txt

Stores all book information.

Example:

101 C_Programming Dennis 5

102 Java Herbert 3

---

### issued.txt

Stores issued book records.

Example:

101 Manoja

102 Kavya
